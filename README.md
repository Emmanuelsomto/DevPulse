# Tech Stories Feed

A modern, responsive web application built with React and Tailwind CSS that curates and displays developer articles and engineering insights.

## Features

- **Tag Filtering**: Filter articles by dynamic categories including React, JavaScript, Tailwind CSS, CSS, Web Dev, and Next.js.
- **Article Preview Cards**: Displays article banners, author avatars, reading times, reaction counts, and publication dates.
- **Direct Navigation**: Seamlessly open full articles on external publishing platforms in new browser tabs.
- **Responsive Grid**: Adaptive multi-column grid system built for desktop, tablet, and mobile displays.

## Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **Icon Library**: React Icons
- **Avatars**: DiceBear API (Avataaars)
